## Non-blocking paste

The complete clipboard transaction is serialized in Grain's options entry
point, so normal and caret-fitted pastes share the same protection. Snapshot,
delays, external scripts and restoration run off the main thread; Enigo input
injection returns to the main thread as required by macOS TIS APIs. Preserve
Agent-panel dictation, Paste Catch, auto-submit and reliable-paste behavior.

Standard, Flow and Native ASR await one small Grain-owned adapter using the
existing blocking pool. No detached paste manager or new service is introduced.
Awaiting delivery preserves their existing completion/history ordering and
surfaces worker failures through the current paste-error path. The two Agent
paste callers already own worker threads and need no scheduling change.

After delivery, tray resets are conditional on the original capture still
owning the session. Overlay completion events already carry the original
session ID and are rejected by the existing presentation state when stale.
Flow's terminal model-error event is similarly gated, avoiding an old error
overwriting a newer capture's presentation.
