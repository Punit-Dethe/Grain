but behavior was deliberately deferred. This ledger distinguishes remaining
implementation holds from ports now implemented but awaiting native-device
acceptance. A zero-behind count and a passing divergence ratchet do not close
either kind. Do not partially copy Handy code across Grain capture, Flow, pill

generations are restored without adopting #1954's ring-buffer rewrite. Handy's
compiled WebView lifecycle now owns overlay platform handling. The macOS accessory and main-window accelerator ports now require native
