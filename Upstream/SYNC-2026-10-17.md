## Native API findings

Audited upstream transcribe.cpp `v0.4.0` at
`f1dcd15858c4bbba87ca97862b4e448b2cf15b8f` against the active Grain fork
`2d336ea878ded786f63dd53520beed8fc6192c61` (upstream 0.2.3).

| Surface                   | Finding and consequence                                                                                                                                                                                                                                                       |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Handy chunker             | Prefers pauses near 30 seconds, normally caps chunks at 40 seconds and uses 5 seconds of live lookahead. Clips up to 40 seconds stay whole; VAD is lazy and failures leave remaining audio uncut. Streaming/long-form capability decides applicability.                       |
| Text seams                | Script-aware joining trims and inserts spacing, but does not reconcile capitalization/punctuation across independently decoded chunks. Shared final-text cleanup follows assembly. Pauses reduce, but do not eliminate, sentence-boundary problems.                           |
| Native Parakeet streaming | Public `ParakeetStreamOptions` and `ParakeetBufferedStreamOptions` serve trained streaming variants, e.g. Nemotron and Unified. Offline TDT v2/v3 do not become streaming models because these APIs exist.                                                                    |
| Native Parakeet long-form | Models with a VAD head advertise `Feature::LongForm` and segment inside native inference. Handy's policy comment mentioning Whisper is not an exhaustive model list; trust loaded-model capabilities.                                                                         |
| Grain v2                  | Ordinary native runs, bounded phase-aligned windows capped at 24 seconds, quiet cuts near the ceiling; no v3 PKFW decode policy. Merged token IDs still require sequence detokenization.                                                                                      |
| Grain v3                  | Custom `ParakeetTdtWindowOptions`/PKFW run extension, reviewed 15-second geometry, context filtering and timestamp offsets.                                                                                                                                                   |
| Fork retirement           | The audited public C headers and safe Rust model API expose no equivalent PKFW run extension or exported sequence-detokenization API. Keep the fork until semantic equivalence is implemented and tested. A generic tokenizer or token-to-piece getter alone is insufficient. |
| Vocabulary                | `RunOptions::vocabulary`, `prompt` and `prefix` are feature-gated. Whisper family `initial_prompt` cannot coexist with generic vocabulary/prompt. Do not send both.                                                                                                           |

Evidence: native `include/transcribe.h`, `include/transcribe/parakeet.h`,
`bindings/rust/transcribe-cpp/src/{family,model,session}.rs`, and
`src/arch/parakeet/{model.cpp,longform.h}`; Grain `src-tauri/src/tdt_flow.rs`,
`crates/grain-tdt/src/{layout,native_layout}.rs`, and `native/transcribe-fork.json`.
These are source findings, not runtime parity or performance measurements.
