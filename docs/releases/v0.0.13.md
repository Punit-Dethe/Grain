# Grain v0.0.13 for Windows

## Recall

- Redesigned the Recall page: a cleaner recordings list, a floating capture
  dock with labelled sources, and search built into the dock.
- Added a meeting view with Transcript, Summary and Ask AI tabs, a slim
  player that starts instantly, and coloured speaker names.
- Turn any audio source on or off mid-recording, with live level meters.
- Added settings to transcribe on stop and to generate summaries and titles
  automatically. Edit recording titles in place.

## Extensions

- Added many new extensions, tested for one-click sign-in with Agent,
  including Linear, Todoist, Dropbox, Asana, Coda, Readwise, Raindrop.io,
  monday.com, Canva, and Jira & Confluence.
- All MCP connections now live in one searchable, alphabetical list.
- Improved sign-in reliability and made Agent turns faster by caching each
  extension's tool list.

## Agent

- Redesigned the Agent notch: smoother growth, a monochrome look, a fade
  that follows your voice, and a close animation that retracts into the
  screen edge.

## Dictation

- If a paste misses its text field, Grain now offers to copy the text to the
  clipboard.
- Grain suggests dictionary terms from the edits you make to dictated text.
- Dictation now pastes into Windows terminals.
- Filter transcription history by date.
