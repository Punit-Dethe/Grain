# Grain v0.0.12 for Windows

## Overview and dictation

- Updated the Overview screen.
- Made dictation faster and unified model selection. Grain uses the selected
  speech model for dictation and Agent voice input.

## Extensions

- Replaced the extension store with a catalog of preconfigured MCP connections.
  Browse GitHub and Notion, manage each connection from its detail page, or
  add your own remote server under **Configure MCP**.
- Retired Grain-native extensions. Extensions now use MCP for tool discovery
  and calls.
- Fixed GitHub sign-in in Windows builds and restored discovery of GitHub tools
  for Agent. Improved connection stability and recovery across MCP providers.

## Grain Assist

- Moved Agent into a compact top-edge notch that expands to show the first
  reply and the follow-up composer.
- Simplified Agent settings and removed Quick Agent, automatic reply copying,
  and direct paste. Copy individual replies from the conversation.
