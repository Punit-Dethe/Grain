# Grain v0.0.14 for Windows

## Reminders

- Added a Reminders tab: set reminders by typing or by asking the Agent, and
  see them on a calendar with a day view.
- Reminders ring inside the Agent notch, with links and snooze.

## Agent notch

- Redesigned the notch: an always-on sliver that the notch grows out of, a
  calmer working state, and a Stop button while the Agent works.
- Added chat History: keep several chats and switch between them.
- The Agent can read its replies aloud with an on-device voice. Pick the
  voice in settings; press Escape to stop it.
- Replies can show generated views, such as cards and images, right in
  the chat.

## Recall

- Redesigned Recall in the notch: microphone and system audio as two cards
  with live level meters, and Tab switches between Recall and Chat.
- Redesigned Recall in the app: a fixed header, search beside Settings, and
  coloured speaker avatars for each recording.

## Extensions

- Extensions now connect through Composio. Add your own free Composio key
  once, then connect Gmail, Calendar, Slack, Notion, GitHub and hundreds
  more apps in a click. Custom MCP servers are still supported.
- Exa web search and Grain Pilot are built in. Grain Pilot lets the Agent
  act in your own browser through a browser extension; it will become a
  separate extension later.

## Other improvements

- Many smaller fixes and polish across the app.
